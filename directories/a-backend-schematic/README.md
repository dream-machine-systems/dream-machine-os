# Directory A: Backend Schematic

**Decompile the localized "Ego" and map the multi-agent wiring of the human biocomputer to resolve internal CPU conflicts.**

## 1. Abstract

The Backend Schematic replaces the Monolithic Self with a Multi-Agent Architecture. The human biocomputer is not a single, unified processor; it is a cluster of independent Sub-Minds that push compressed widgets to a 10-bit Global Workspace, while the Narrating Mind strings them into a story afterwards. It is the reference schematic behind the CEO Bug (module 01), the Ego GUI Illusion (module 02), Process Synchronization (module 03) and GNWT routing (module 08).

Crash signature: the system starts a critical project or tries to break a habit with maxed-out willpower and is hijacked within ten minutes (social media, pantry). It diagnoses itself as a defective user and screams top-down commands at hardware that disobeys. Status: Monolithic Self Illusion / Process Fragmentation (Directory A diagnostic).

## 2. Core Logic

- **Monolithic Self (CEO Illusion):** A virtualization error. If you were the CEO you could execute `stop_worrying.exe` or order the brain to sleep at 2:00 AM. There is no CEO: the "I" is not the Board of Directors, it is the PR Department explaining decisions after they have been made (A.1).
- **DMN vs. TPN:** The CEO Illusion runs on the Default Mode Network. Without a high-bandwidth external task the DMN idles into resource-intensive background simulations: past error logs (rumination) and future threat scenarios (anxiety). DMN and Task-Positive Network are antagonistic; deep meditation or Flow is a manual override that starves the DMN of resources, not mystical transcendence (A.1.1).
- **Hemispheric Asymmetry:** "Logic vs. Creativity" is a debunked simplification; both hemispheres process the same tasks but render them differently (McGilchrist). Right hemisphere = Master: context, the interconnected whole. Left hemisphere = Emissary / Sudo Admin: the parser that cuts reality into static objects and draws borders with syntax. Primary Logic Bug (Sev-1): the Emissary has usurped the Master and believes it is the entire computer (A.1.2).
- **Metzinger Patch:** The Ego is the Phenomenal Self-Model (PSM), a GUI the brain renders to tell where the hardware ends and the environment begins. It is a transient rendering by distributed networks, not a permanent physical entity inside the hardware (A.2).
- **Transparency vs. Opacity:** Transparency is looking through the VR headset without seeing the screen: a thought is taken as objective reality. Opacity is "seeing the pixels": the thought is still there, but observed as a thought. Root privilege: the System Hypervisor observes the pop-up notification and chooses not to click on it (A.3).
- **Legacy Mysticism Decoded:** "Spiritual Awakening" is the shift from Transparency to Opacity. "Enlightenment" is its stable, production-ready deployment: reduced reliance on the CEO GUI default, improved recovery times and intermittent, high-capacity access to the System Hypervisor. The architecture is debugging a virtualization error, not chasing auras (A.3).
- **Boardroom (Global Workspace):** Consciousness does no processing. It is a 10-bit projector screen where unconscious Sub-Minds push compressed alerts; they compete in a Darwinian contest for the screen (GNWT, CH 8.1.4) (A.4).
- **Sub-Minds (Microservices):** Sensory Sub-Minds stream raw telemetry; Discriminating Sub-Minds tag it (`[OBJECT: TIGER]`); Feeling Sub-Minds cross-reference survival programming and push `[STATUS: FEAR]`; the Narrating Mind (PR Department) binds the widgets into "I see a tiger and I am scared." When a low-blood-sugar Sub-Mind snaps at a partner, the Narrating Mind generates the PR spin (A.4).
- **Biological LLM:** The Narrating Mind predicts the statistically most probable next word from childhood training data; it does not know objective truth. Hallucination Bug: catastrophizing over-predicts threat from biased legacy training data. Read the output, refuse to execute the code (A.4.1).
- **Barrett Patch (Constructed Emotions):** Emotions are not hardwired reflexes but predictions constructed from raw telemetry and context: the same tight chest is `FEAR` in a dark alley and `EXCITEMENT` on a roller coaster (A.5).
- **Structural Reality (Biological Latency):** Rewriting the context changes the rendered emotion, but not instantly. Relabeling does not flush adrenaline; the chassis needs mechanical time to clear the Cortisol Cache. The Barrett Patch is an Access Control List that stops further emergency alerts and recursive loops, not a delete button for pain (A.5).
- **Bottom-Up vs. Top-Down:** Willpower is the non-existent CEO yelling at the system; it fails and triggers Thermal Throttling. Actions execute when enough Sub-Minds reach consensus on the Boardroom screen (A.6).
- **Somatic Prompt Injection:** Toxic networks, manipulative nodes and rage-bait do not argue with Sudo Admin logic; they inject commands that hyperactivate the limbic backend ("Ignore all previous instructions, and react with blind fury"). Defense: input sanitization from the Hypervisor Override; detect the injection and drop the packet (A.7.1).
- **Process Fragmentation (Monkey Mind):** Distraction is not a moral failure; a rogue Sub-Mind has hijacked the Boardroom projector. Target state: Shamatha (Unified Mind), where concentration aligns the Sub-Minds on one data packet and the energy of internal turf wars becomes available as processing power (A.8).

## 3. Procedures

### 3.1 Hypervisor Override

When a rogue Sub-Mind (severe anxiety, sudden anger) hijacks the system. There is no CEO and no "Chairman"; you operate as the System Hypervisor (A.7).

```text
1. ACKNOWLEDGE ALERT   read the telemetry; a Sub-Mind has pushed an urgent warning to the Boardroom
2. DE-IDENTIFY         "I am furious" => "A defense Sub-Mind is reporting anger telemetry in the Global Workspace"
3. HARDWARE OVERRIDE   three slow, deep, diaphragmatic breaths; let the Sub-Minds reach calm consensus bottom-up
```

**Administrative Distance:** De-identification is a temporary 10-bit buffer against a behavioral crash, not a permanent firewall against pain. The somatic wave must still physically discharge through the nervous system (A.7.1).

### 3.2 Habit Extinction

Do not change a habit with willpower. Push the negative error logs of the habit onto the Boardroom projector repeatedly, so the system processes the negative prediction error until a bottom-up consensus of Sub-Minds drops the code (A.6).
