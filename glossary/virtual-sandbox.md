An isolated simulation environment for testing new code without real-world consequences. Awake: Mental Rehearsal, where the Admin simulates a trigger in stillness and pre-compiles the new response (Chapter 2.4.1). Asleep: Lucid Dreaming, a state where the conscious Admin retains Root Access while the physical hardware is in sleep mode (Chapter 5.4).
