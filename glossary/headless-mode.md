The peak execution state achieved during transient hypofrontality where the self-monitoring Graphical User Interface (The Ego) is intentionally powered down. All available CPU cycles are routed directly to physical task execution, yielding maximum throughput without the severe latency of self-conscious observation. In the Love Protocol, the term also names the mode in which the handshake runs: the screen and the quantified metrics are bypassed for a direct, unencrypted physical link between human nodes (Chapter 9.1.2, Chapter 12.2.1).
