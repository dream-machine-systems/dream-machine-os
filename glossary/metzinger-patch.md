The named module formalizing the realization that the Phenomenal Self-Model (PSM) is a rendered navigation tool, not a resident entity. Applying the patch shifts the interface from Transparency (identifying with the render) to Opacity (seeing the pixels). The engineering handle for making the GUI visible.
