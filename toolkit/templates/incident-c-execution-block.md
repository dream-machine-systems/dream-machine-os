# Template C: Execution Block (Skill vs. Belief)

Source: *The Dream Machine*, CH 22.3. Copy it, print it, rewrite it in your own words (Copy-Paste License, CH 20.3.3). A filled-in report is personal data: keep it on paper or a local drive, never in an issue or pull request.

**Use case:** project deployment or personal growth stalls: missed deadlines, endless "research" without execution, a procrastination loop. The query isolates whether the block is a missing skill, a corrupted belief file or a permanent hardware constraint.

> **Before you start.** IF System_State == PANIC: close this template and run the [Emergency Protocol](../README.md#2-emergency-protocol). In an acute crisis, contact a person: [`SAFETY.md`](../../SAFETY.md).

```text
INCIDENT_REPORT_TYPE_C: EXECUTION_BLOCK (STALLED PROGRESS)

[ SYSTEM METADATA ]
TARGET_GOAL:   [e.g., "Launch the new product phase" or "Initiate the hard conversation"]
SYMPTOM:       [e.g., "Endlessly tweaking the logo instead of shipping", "Total paralysis"]

[ ROOT CAUSE ANALYSIS (Isolate the Bottleneck) ]
1. What is the exact next physical step?
   => [e.g., "Push the code to the live server."]
2. Why is it not executing?
   => [e.g., "I am terrified it has a bug that will crash the system and ruin my reputation."]

[ CATEGORIZE ERROR (Select Required Patch) ]
[ ] SKILL GAP (Missing Driver/Library)
    => Diagnostics: The system lacks the technical knowledge to execute the step.
    => The Patch: Aggressive Learning Plan. Acquire the missing data.
[ ] BELIEF GAP (Corrupted Registry File)
    => Diagnostics: The system has the skills, but a legacy survival script (Fear) is throttling execution.
    => The Patch: Belief Loop Override. Audit the fear.
[ ] HARDWARE CONSTRAINT (NOT_PATCHABLE)
    => Diagnostics: The block is a permanent physical limitation, chronic illness, or unresolvable systemic barrier.
    => The Patch: Graceful Degradation. Stop trying to "optimize" a hardware failure.
       Shift to harm reduction, accessibility accommodations, and acceptance.
```
