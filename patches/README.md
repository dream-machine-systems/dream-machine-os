# Patches

Third-party frameworks mapped onto the OS. A patch never replaces the source framework; it translates it into system logic and names its evidence tier.

| Patch | Source | Tier | Targets |
| --- | --- | --- | --- |
| [Gottman Method](gottman.md) | Dr. John Gottman | `TIER 1: CLINICAL` | 01, 08 |
| [Terry Real Boundary Logic](terry-real.md) | Terry Real | `UNAUDITED` | 01, 09 |
| [Dispenza Neural Refactoring](dispenza.md) | Dr. Joe Dispenza | `TIER 3: EXPERIMENTAL` | 01 |

Tier definitions: [CONTRIBUTING.md](../CONTRIBUTING.md#evidence-tiers). New patches go through an [RFC](../rfcs/README.md).

Names of methods and authors are used to identify the source framework. No endorsement by the original authors is implied.
